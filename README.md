# Valentine React + Vite App

A responsive two-screen Valentine experience built as a standard React and
Vite single-page application.

## Run locally

```bash
npm install
npm run dev
```

The development server tries `http://localhost:5173` first. If that port is
occupied, Vite automatically chooses the next available local port and prints
the exact URL in the terminal.

## Build

```bash
npm run build
```

The production build is written to `dist/`.
