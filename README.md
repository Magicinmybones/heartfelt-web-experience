# Valentine React + Vite App

A responsive two-screen Valentine experience built as a standard React and
Vite single-page application.

## Run locally

```bash
npm install
npm run dev
```

The development server runs at `http://localhost:5173` and uses a strict port,
so it will report an error instead of silently switching to another port.

## Build

```bash
npm run build
```

The production build is written to `dist/`.
